# ওয়েব শিখি - বাংলায় HTML, CSS, Tailwind ও JavaScript শেখার প্ল্যাটফর্ম

শূন্য থেকে শুরু করে HTML ও CSS-এর মৌলিক থেকে অ্যাডভান্সড পর্যন্ত বাংলায় ধাপে ধাপে শেখার একটি স্ট্যাটিক ওয়েবসাইট। কোনো সার্ভার, ডাটাবেস বা রেজিস্ট্রেশন লাগে না।

## কীভাবে চালাবেন

### পদ্ধতি ১: ফাইল সরাসরি খোলা
ব্রাউজারে `/sdcard/HTML/index.html` ফাইলটি খুলুন। বেশিরভাগ লেসন ও প্লেগ্রাউন্ড এভাবে কাজ করে।

### পদ্ধতি ২: লোকাল সার্ভার (সুপারিশকৃত)
Termux-এ:
```
cd /sdcard/HTML
python3 -m http.server 8080
```
তারপর ব্রাউজারে `http://localhost:8080` খুলুন।

কম্পিউটারে (Python আছে ধরে):
```
cd HTML
python3 -m http.server 8080
```

> JavaScript course-এর Fetch লেসনের উদাহরণ লোকাল সার্ভার ছাড়া (`file://`) কাজ করে না। সেখানে বিস্তারিত লেখা আছে।

## ইন্টারনেট ও নির্ভরতা
- **Google Fonts (Hind Siliguri)**: ইন্টারনেট থাকলে বাংলা ফন্ট লোড হয়। না থাকলে সিস্টেমের বাংলা ফন্ট ব্যবহৃত হয়।
- **Tailwind CSS Play CDN (`@tailwindcss/browser@4`)**: Tailwind লেসন ও প্লেগ্রাউন্ডের Tailwind উদাহরণে ব্যবহৃত হয়। এটি শেখার জন্য; প্রোডাকশনের জন্য নয়। ইন্টারনেট ছাড়া Tailwind উদাহরণ কাজ করবে না।
- প্ল্যাটফর্মের নিজস্ব স্টাইল (`assets/css/style.css`) ও JavaScript বাইরের কোনো লাইব্রেরি ছাড়া লেখা, তাই অফলাইনেও প্লেগ্রাউন্ড ও লেসন দেখা যায়।

## ফিচার
- **ড্যাশবোর্ড**: স্বাগতম বার্তা, মোট/সম্পন্ন/বাকি লেসন, সামগ্রিক অগ্রগতি, শেখার পথ (Roadmap), সুপারিশকৃত পরবর্তী লেসন, "শেখা চালিয়ে যান" বাটন।
- **লেসন পেজ**: শেখার উদ্দেশ্য, বাংলা ব্যাখ্যা, কেন দরকারী, সিনট্যাক্স, কোড উদাহরণ (হাইলাইট ও কপি বাটনসহ), লাইন বাই লাইন ব্যাখ্যা, প্রত্যাশিত আউটপুট, সাধারণ ভুল, সেরা অনুশীলন, বাস্তব ব্যবহার, তিনটি অনুশীলন (সহজ/মাঝারি/কঠিন), কুইজ, আগে/পরে নেভিগেশন, "সম্পন্ন হিসেবে চিহ্নিত করুন"।
- **সাইডবার**: কোর্স ও মডিউল ধরে লেসন তালিকা, বর্তমান লেসন হাইলাইট, সম্পন্ন লেসনের চিহ্ন, মোবাইলে অফ-ক্যানভাস মেনু, ডেস্কটপে গুটিয়ে রাখার সুবিধা।
- **খোঁজ**: শিরোনাম, মডিউল ও বিষয়বস্তু ধরে লেসন খোঁজা।
- **থিম**: লাইট/ডার্ক মোড, পছন্দ সংরক্ষিত থাকে।
- **কোড প্লেগ্রাউন্ড**: আলাদা HTML, CSS, JavaScript এডিটর; লাইভ প্রিভিউ (sandbox iframe, `allow-scripts` ছাড়া আর কিছু নেই); কোড চালান, উদাহরণ রিসেট, সম্পূর্ণ কোড কপি; ৮টি উদাহরণ; রানটাইম ত্রুটি প্রিভিউর নিচে দেখায়। লেসনের "Playground-এ চালান" বাটন উদাহরণ সরাসরি এখানে খোলে।
- **কুইজ**: প্রতি লেসনে ৩টি প্রশ্ন, তাৎক্ষণিক ফিডব্যাক, সঠিক/ভুল চিহ্ন, বাংলা ব্যাখ্যা, স্কোর, আবার দেওয়ার সুবিধা। মডিউল কুইজে সর্বোচ্চ স্কোর সংরক্ষিত হয়।
- **প্রজেক্ট**: ১০টি প্রজেক্টের প্রয়োজনীয়তা, ধাপে ধাপে নির্দেশনা, HTML/CSS/রেসপন্সিভ/অ্যাক্সেসিবিলিটি ব্যাখ্যা, Tailwind বিকল্প, স্টার্টার কোড। কয়েকটির সম্পূর্ণ সমাধানও আছে।
- **রেফারেন্স**: HTML ট্যাগ/অ্যাট্রিবিউট/ইনপুট টাইপ, CSS সিলেক্টর/প্রপার্টি/ইউনিট/Flexbox/Grid/মিডিয়া কোয়েরি/ব্রেকপয়েন্ট, Tailwind ক্লাস, DOM মেথড, সাধারণ ভুল ও সমাধান। খোঁজা যায়।
- **অগ্রগতি**: সামগ্রিক ও কোর্সভিত্তিক অগ্রগতি, কুইজ স্কোর, নিশ্চিতকরণসহ রিসেট।

## অগ্রগতি সংরক্ষণ সম্পর্কে
অগ্রগতি, কুইজ স্কোর ও থিম এই ব্রাউজার ও ডিভাইসের **LocalStorage**-এ (`bdlearn.v1` কী) সংরক্ষিত হয়। ব্রাউজারের ডেটা মুছলে, প্রাইভেট মোডে, বা অন্য ডিভাইসে গেলে অগ্রগতি দেখা যাবে না। কোনো তথ্য সার্ভারে পাঠানো হয় না।

## নিরাপত্তা
- প্লেগ্রাউন্ডের কোড `<iframe sandbox="allow-scripts">`-এর ভেতরে চলে, `allow-same-origin` নেই; তাই এটি মূল পেজের DOM বা LocalStorage-এ প্রবেশ করতে পারে না।
- মূল অ্যাপে `eval()` ব্যবহার হয় না।
- লেসনের লেখা ও ব্যবহারকারীর ইনপুট `textContent` দিয়ে বসানো হয়; কোড হাইলাইটের আগে সব অক্ষর escape করা হয়।
- সীমাবদ্ধতা: অসীম লুপ (`while (true)`) চালালে প্রিভিউ আটকে যেতে পারে; পেজ রিফ্রেশ করুন।

## কনটেন্ট যোগ বা সম্পাদনা করার নিয়ম
লেসন `assets/js/data/*.js` ফাইলে `window.LESSONS.push(...[ ... ])` আকারে লেখা। প্রতিটি লেসনে আবশ্যিক ফিল্ড: `id`, `course`, `module`, `moduleTitle`, `order`, `title`, `objectives`, `explanation`, `example`, `lineByLine`, `output`, `mistakes`, `bestPractices`, `useCase`, `practice` (ঠিক ৩টি: easy, medium, challenging), `quiz` (৩টি প্রশ্ন, প্রতিটিতে ৪টি অপশন)। লেখার পর `node --check <file>` চালালে সিনট্যাক্স যাচাই হয়। লেসন বা প্রশ্নে ভুল থাকলে `app.js` কনসোলে সতর্কবার্তা দেয় এবং সেই লেসন বাদ পড়ে।

## বর্তমান অবস্থা ও সীমাবদ্ধতা
- **সম্পন্ন কনটেন্ট:** HTML মডিউল ১-২ (১৬টি লেসন), CSS মডিউল ১ (৮টি লেসন), Tailwind CSS মডিউল ১-২ এর কিছু অংশ (৪টি লেসন), JavaScript মডিউল ১ ও ২ এর শুরু (৬টি লেসন), ১০টি প্রজেক্ট, রেফারেন্স (দুই অংশ)।
- **এখনো যুক্ত হয়নি:** HTML মডিউল ৩ (ফর্ম), ৪ ও ৫ (অ্যাডভান্সড); CSS মডিউল ২-৪ (লেআউট, রেসপন্সিভ, অ্যাডভান্সড); Tailwind-এর রেসপন্সিভ নেভিগেশন থেকে শেষ পর্যন্ত; JavaScript-এর ফর্ম ভ্যালিডেশন থেকে Fetch পর্যন্ত। এই লেসনগুলো `assets/js/data/` ফাইলে একই নিয়মে যোগ করা যাবে এবং `index.html`-এ স্ক্রিপ্ট ট্যাগ যুক্ত করতে হবে।
- লেসন পেজে কোনো লেসন "লক" করা হয় না, যাতে শিক্ষার্থী যেকোনো লেসনে যেতে পারে।
- প্রজেক্টের অনেকগুলোতে শুধু স্টার্টার কোড আছে, সম্পূর্ণ সমাধান নেই।
- কোডের স্বয়ংক্রিয় যাচাই (auto-grading) নেই; অনুশীলনের সমাধান "সাজেস্টেড সমাধান" হিসেবে দেখানো হয়।
- প্লেগ্রাউন্ডে অসীম লুপ থেকে রক্ষার কোনো টাইমআউট নেই।
- পেজগুলো একক পেজ অ্যাপ হিসেবে (হ্যাশ রাউটিং: `#/lesson/...`) তৈরি; আলাদা `pages/*.html` ফাইল নেই। এতে ব্রাউজারের Back/Forward কাজ করে।
